# 유사 타겟·유사 목적 논문 존재 여부 조사

작성일: 2026-06-28.
대상 초안: `인코더-디코더 구조를 이용한 유도탄 데이터 점검 방법`.
조사 질문: 국내외에 유사 논문이 존재하는가. 특히 유사 타겟과 유사 목적을 갖는 논문이 있는가.

## 1. 판정 기준

본 조사는 유사도를 세 단계로 나누었다.

| 구분 | 판정 기준 | 중복 위험 |
|---|---|---|
| 직접 유사 | 유도탄, 미사일 FCS, 무기체계 시험·정비 데이터가 대상이고 목적이 이상탐지 또는 데이터 점검인 경우 | 높음 |
| 부분 유사 | 항공우주 텔레메트리, 레이더, 산업제어, 시험장비 데이터가 대상이고 목적이 이상탐지 또는 점검인 경우 | 중간 |
| 방법론 유사 | 대상은 다르지만 Enc-Dec, Autoencoder, LSTM, Transformer 기반 시계열 이상탐지인 경우 | 낮음에서 중간 |

## 2. 결론 요약

- 국내에는 직접 유사 논문이 존재한다.
- 가장 직접적인 논문은 KIMST 2025 추계학술대회의 `인공지능 기반 DAS 데이터 분석을 통한 미사일 발사통제체계(FCS) 실시간 이상 탐지 방법 제안`이다.
- 이 논문은 미사일 FCS의 DAS 통신 로그를 대상으로 시간 편차, 메시지 손실, 지터를 시계열 모델과 규칙 기반 임계값으로 탐지한다.
- 현재 초안과 유사한 점은 `유도무기체계 데이터`, `이상탐지`, `AI 모델 + 규칙 기반 검증`, `실무 점검 목적`이다.
- 차이점은 해당 논문이 FCS 통신 메시지 중심이고, 현재 초안은 센서값·상태 플래그·이벤트 로그를 포함하는 일반화된 데이터 품질 점검과 Enc-Dec 복원오차 구조를 제안한다는 점이다.
- 국외에서는 `유도탄 데이터 Enc-Dec 점검`과 동일한 공개 논문은 확인하지 못했다.
- 다만 우주기 텔레메트리, 레이더 데이터 스트림, 산업제어 운용 데이터 이상탐지 논문이 부분 유사 또는 방법론 유사로 다수 존재한다.

## 3. 국내 유사 논문

### 3.1 직접 유사 논문

#### Kim et al., 인공지능 기반 DAS 데이터 분석을 통한 미사일 발사통제체계(FCS) 실시간 이상 탐지 방법 제안

- 출처: KIMST 2025 추계학술대회, 유도무기체계.
- 링크: https://www.kimst.or.kr/electronic_paper/pdf_down.kin?idx=25675.
- 대상: 미사일 발사통제체계(FCS)의 DAS 통신 로그.
- 목적: 주기 메시지의 시간 편차, 메시지 손실, 지터를 실시간 이상으로 탐지.
- 방법: 시계열 모델, LSTM 또는 GRU 계열 예측, 규칙 기반 임계값 검증.
- 유사도: 직접 유사.
- 중복 위험: 높음.
- 현재 초안과의 차이: 현재 초안은 FCS 통신 메시지에 한정하지 않고 유도탄 데이터 점검 일반 절차를 다루며, 예측 모델보다 Enc-Dec 복원오차 기반 점검 구조를 중심에 둔다.
- 보완 필요: 초안 서론에서 이 논문을 반드시 언급하고, “기존 연구는 FCS 주기 메시지 중심이며 본 연구는 센서·상태·이벤트 로그를 포함한 일반 데이터 품질 점검 구조를 제안한다”는 차별점을 명시해야 한다.

### 3.2 목적 유사 국내 논문

#### Kim et al., GAN을 활용한 무기체계 PHM 분석 이상 탐지 방안 연구

- 출처: KIMST 2022 종합학술대회, 체계공학.
- 링크: https://www.kimst.or.kr/electronic_paper/pdf_down.kin?idx=20294.
- 대상: 무기체계 PHM 데이터.
- 목적: 고장 데이터 부족과 데이터 불균형 문제를 합성데이터 관점에서 완화.
- 방법: GAN 및 시계열 GAN 계열 검토.
- 유사도: 부분 유사.
- 중복 위험: 중간.
- 현재 초안과의 차이: 이 논문은 PHM과 합성데이터 생성 가능성 중심이고, 현재 초안은 정상 데이터 기반 Enc-Dec 점검 절차 중심이다.
- 보완 필요: 초안의 문제 정의에서 “비정상 라벨 부족” 근거로 활용하면 적합하다.

#### Min and Jin, 빅데이터 기반 창정비용 시험장비 시험결과 DB 분석 SW 개발

- 출처: KIMST 2025 종합학술대회, 구조·기기.
- 링크: https://www.kimst.or.kr/electronic_paper/pdf_down.kin?idx=24227.
- 대상: 창정비 시험장비와 시험대상품의 시험결과 DB.
- 목적: 단순 합부 판정에서 누적 데이터 기반 비교·추이 분석으로 확장.
- 방법: 시험결과 Raw Data DB화, 그래프 기반 비교분석 SW.
- 유사도: 부분 유사.
- 중복 위험: 낮음에서 중간.
- 현재 초안과의 차이: AI 이상탐지 논문은 아니며 시험결과 데이터 관리와 분석 SW 중심이다.
- 보완 필요: 초안의 기대 효과에서 “시험 데이터의 누적 관리와 비교분석 필요성” 근거로 활용하면 좋다.

### 3.3 국내 검색 결과에서 확인된 추가 후보

KIMST 공식 자료검색에서 `이상 탐지`, `유도`, `데이터` 키워드로 확인한 결과 다음 후보도 있었다.

- `탭형 데이터에서 학습 가능한 제약 마스킹을 활용한 이상 탐지`.
- `Brent 알고리즘을 이용한 OBF-ML 기반 자기 이상 탐지`.
- `AI 기반 자기 이상 탐지 기법을 이용한 지뢰 탐지 연구`.
- `드론 기반 자기 이상 탐지를 이용한 해양에서의 강자성 표적 탐지`.
- `군용 차륜 차량 내구시험 데이터 기반 NSGA-II를 이용한 다목적 최적화 결과 비교`.
- `DoDAF Meta Model 기반 무기체계 성능시험 지원 자산의 데이터 모델 구현`.

위 후보들은 국방 데이터 또는 이상탐지라는 점에서는 유사하지만, 유도탄 데이터 점검 및 Enc-Dec 기반 시계열 이상탐지와는 직접성이 낮다.

## 4. 국외 유사 논문

### 4.1 직접 유사 국외 논문 존재 여부

공개 검색 기준으로 `guided weapon data inspection`, `missile telemetry anomaly detection`, `missile fire control system anomaly detection`, `missile control system data anomaly detection`, `launch vehicle telemetry anomaly detection` 조합을 확인했으나, 현재 초안과 같이 `유도탄 데이터 점검`과 `Enc-Dec 복원오차`를 함께 다루는 직접 유사 국외 논문은 확인하지 못했다.

다만 아래 논문들은 타겟 또는 목적이 상당히 가깝다.

### 4.2 부분 유사 국외 논문

#### Hundman et al., Detecting Spacecraft Anomalies Using LSTMs and Nonparametric Dynamic Thresholding

- 링크: https://arxiv.org/abs/1802.04431.
- 대상: NASA SMAP 위성 및 MSL 로버 텔레메트리.
- 목적: 운용 엔지니어의 모니터링 부담과 운용 위험을 줄이기 위한 텔레메트리 이상탐지.
- 방법: LSTM 예측 오차, 비모수 동적 임계값, 오탐 완화.
- 유사도: 부분 유사.
- 중복 위험: 중간.
- 차이점: 대상은 우주기 텔레메트리이고, 방법은 Enc-Dec 복원이 아니라 예측 오차와 동적 임계값이다.
- 초안 활용: 유도탄 계측 데이터도 항공우주 텔레메트리와 유사한 시계열 점검 문제가 있음을 설명하는 근거로 좋다.

#### Cohen et al., RadArnomaly: Protecting Radar Systems from Data Manipulation Attacks

- 링크: https://arxiv.org/abs/2106.07074.
- 대상: 항공기, 미사일, 위성 등을 추적하는 레이더 시스템 데이터 스트림.
- 목적: 레이더 데이터 조작과 메시지 드롭 공격 탐지.
- 방법: 수치형·범주형 특성의 상관관계 학습, 시간 간격 이상탐지.
- 유사도: 부분 유사.
- 중복 위험: 중간.
- 차이점: 레이더 데이터 보호와 사이버 조작 탐지가 중심이며, 유도탄 자체 시험·정비 데이터 점검은 아니다.
- 초안 활용: 상태 플래그와 수치형 채널 간 관계 점검 필요성을 설명할 때 보조 근거로 활용 가능하다.

#### Kim et al., Anomaly Detection for Industrial Control Systems Using Sequence-to-Sequence Neural Networks

- 링크: https://arxiv.org/abs/1911.04831.
- 대상: 산업제어시스템 운용 데이터.
- 목적: 정상 데이터만으로 시계열 특성을 학습하고 이상점을 탐지.
- 방법: Sequence-to-Sequence Neural Network, SWaT 데이터 평가.
- 유사도: 방법론 유사에 가까운 부분 유사.
- 중복 위험: 낮음에서 중간.
- 차이점: 대상은 산업제어시스템이고 무기체계 데이터가 아니다.
- 초안 활용: 정상 데이터 기반 시계열 모델링과 점검 구조의 일반 근거로 활용 가능하다.

#### Lakey and Schlippe, A Comparison of Deep Learning Architectures for Spacecraft Anomaly Detection

- 링크: https://arxiv.org/abs/2403.12864.
- 대상: 우주기 데이터.
- 목적: 우주기 이상탐지를 위한 CNN, RNN, LSTM, Transformer 구조 비교.
- 방법: 여러 딥러닝 아키텍처 비교.
- 유사도: 부분 유사.
- 중복 위험: 낮음에서 중간.
- 차이점: 모델 비교 연구이며 단순 Enc-Dec 점검 절차 논문은 아니다.
- 초안 활용: 고찰에서 “복잡한 구조는 성능을 높일 수 있으나 운용 제약과 계산 비용을 고려해야 한다”는 논리에 유용하다.

### 4.3 방법론 유사 국외 논문

#### Malhotra et al., LSTM-based Encoder-Decoder for Multi-sensor Anomaly Detection

- 링크: https://arxiv.org/abs/1607.00148.
- 대상: 다중 센서 시계열.
- 목적: 정상 패턴 학습 후 복원 오차 기반 이상탐지.
- 방법: LSTM Encoder-Decoder.
- 유사도: 방법론 직접 유사.
- 중복 위험: 방법론 측면에서는 높지만 타겟 측면에서는 낮음.
- 초안 활용: Enc-Dec 복원오차 방식의 핵심 선행연구로 반드시 인용해야 한다.

#### MAD-GAN, TAnoGAN, TadGAN 계열

- MAD-GAN 링크: https://arxiv.org/abs/1901.04997.
- TAnoGAN 링크: https://arxiv.org/abs/2008.09567.
- TadGAN 링크: https://arxiv.org/abs/2009.07769.
- 대상: 일반 다변량 또는 단변량 시계열.
- 목적: 비지도 이상탐지.
- 방법: GAN 기반 재구성 또는 판별 점수.
- 유사도: 방법론 유사.
- 중복 위험: 낮음.
- 초안 활용: 현재 초안에는 직접 반영하지 않아도 되며, PHM/GAN 국내 논문을 보조할 때만 언급하는 것이 적절하다.

## 6. 현재 초안의 차별화 문장 권장

현재 초안은 다음 차별점을 명확히 해야 한다.

1. 기존 국내 유사 연구는 FCS DAS 주기 메시지 또는 특정 무기체계 PHM 문제에 초점을 둔다.
2. 본 논문은 유도탄 시험·정비 데이터의 사전 품질 점검 절차를 일반화해 센서값, 상태 플래그, 이벤트 로그를 함께 다룬다.
3. 본 논문은 고장 분류나 실시간 운용 제어가 아니라 데이터 사용 전 검수와 담당자 검토 우선순위 산출을 목적으로 한다.
4. 본 논문은 복잡한 모델보다 Enc-Dec 복원오차와 명시적 규칙 점검을 결합한 단순 구조를 우선 제안한다.
5. 실제 체계 적용 전에는 비식별 데이터 기반 정량 검증과 체계별 규칙 보완이 필요하다.

권장 문장 예시는 다음과 같다.

> 기존 연구에서는 미사일 발사통제체계의 DAS 주기 메시지를 대상으로 시간 편차, 메시지 손실, 지터를 탐지하는 AI 기반 방법이 제안된 바 있다. 그러나 해당 연구는 통신 메시지의 실시간 이상탐지에 초점을 두며, 센서 계측값, 상태 플래그, 이벤트 로그를 포함한 유도탄 데이터 전반의 사전 품질 점검 절차를 일반화하는 데에는 한계가 있다. 본 논문은 이러한 차이를 고려하여 정상 데이터 기반 Enc-Dec 복원오차와 규칙 기반 점검을 결합한 단순 점검 구조를 제안한다.

## 7. 최종 판단

유사 논문은 존재한다. 특히 국내 KIMST의 미사일 FCS DAS 실시간 이상탐지 논문은 타겟과 목적이 상당히 유사하므로, 현재 초안이 그대로 제출되면 선행연구 검토 부족으로 보일 수 있다.

다만 동일한 논문은 아니다. 현재 초안은 FCS 통신 메시지 이상탐지가 아니라 유도탄 시험·정비 데이터 전반의 사전 점검 절차를 제안하고, Enc-Dec 복원오차와 규칙 기반 검증을 결합하는 방향이다. 따라서 중복 회피를 위해서는 국내 유사 논문을 명확히 인용하고, 데이터 범위와 목적을 `실시간 운용 이상탐지`가 아니라 `데이터 사용 전 품질 점검 및 검토 우선순위 산출`로 분명히 해야 한다.
